SETUP GUIDE — yahoo-stock-fetcher

チャットで話しかけるだけで
株価が返ってくる仕組み

Claude Codeに「〇〇の株価を10日分見せて」と伝えると、裏側でこのツールがYahoo Financeへ問い合わせ、結果を表にして返してくれます。ここでは仕組みと、GitHubに保存するまでの手順をまとめました。

01

仕組み（データの流れ）

4つの登場人物が、毎回この順番で動きます。

You
あなたチャットで「9418の株価を10日分」のように話しかける
↓
CC
Claude Code依頼を読み取り、銘柄コードと日数を組み立てる
↓
.py
get_stock.pyこのスクリプトが実行され、データ取得の窓口になる
↓
YF
Yahoo Finance実際の株価データを送り返してくる
↑ 結果が戻ってくる
02

使い方の例

ターミナルから直接使う場合はこう打ちます。

# 東証9418番、直近10日間
python get_stock.py 9418 10
# 米国株Apple、直近5日間（日数は省略可）
python get_stock.py AAPL
# 結果をCSVでも残したいとき
python get_stock.py 9418.T 10 --csv
Claude Code上では、コマンドを打つ必要はありません。
「ユーネクストの直近10日間の株価を見せて」と話すだけで、Claude Codeが上のコマンドを代わりに実行してくれます。
03

GitHubへ保存する手順

一度リポジトリを作れば、以後は変更のたびに保存（バックアップ）できます。上から順番に進めてください。

GitHub上に空のリポジトリを作る

GitHubにログインし、右上の「＋」→「New repository」を選択。

名前を yahoo-stock-fetcher とし、「Add a README」はチェックを外したまま「Create repository」を押します。

手元のパソコンでGitの初期設定をする（最初の1回だけ）

git config --global user.name "あなたの名前"
git config --global user.email "GitHubの登録メール"

このフォルダをGitリポジトリにする

ダウンロードした yahoo-stock-fetcher フォルダの中でターミナルを開き、実行します。

git init
git add .
git commit -m "初回コミット：株価取得ツール"

GitHubへ接続してアップロードする

手順1で作成したリポジトリのページに表示されている、あなた専用のURLに置き換えて実行します。

git branch -M main
git remote add origin https://github.com/あなたのユーザー名/yahoo-stock-fetcher.git
git push -u origin main
もっと簡単に済ませたい場合：
Claude Codeをこのフォルダで開いた状態で「このプロジェクトをGitHubにアップロードして」と話しかけると、GitHub連携（gh コマンド）が設定済みであれば、ここまでの手順をClaude Codeが代わりに実行してくれます。うまくいかない場合の保険として、この手順書を残しています。
