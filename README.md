# 株価取得ツール（Yahoo Finance版）

チャットで「〇〇の株価を〇日分見せて」と伝えるだけで、Yahoo Financeから株価データを取得するツールです。
Claude Codeと組み合わせて使うことを想定しています。

## できること

- 日本株・米国株どちらも取得可能
- 日付・始値・高値・安値・終値・出来高を一覧表示
- 指数平滑移動平均線（EMA、5日・25日・75日・200日から選択可、デフォルトは全部）を算出して表示
- 出来高の20日移動平均（出来高MA20）と、平均に対する比率を表示（出来高が普段より多いか少ないか一目で分かる）
- 期間中の騰落（値上がり／値下がり）を自動計算
- 必要であればCSVファイルとしても保存

## 事前準備（最初の1回だけ）

1. Python 3.9以上がインストールされていること
2. このフォルダで以下を実行してライブラリを準備します

```bash
pip install -r requirements.txt
```

## 使い方

ターミナルから直接実行する場合：

```bash
python get_stock.py 9418.T 10
```

上記は「9418.T（U-NEXT HOLDINGS）の直近10日間」を取得する例です。

### 銘柄コードの指定方法

| 入力例 | 意味 |
|---|---|
| `9418.T` | 東証の銘柄（.Tを明示） |
| `9418` | 数字だけならツールが自動で `.T` を補完 |
| `AAPL` | 米国株（Apple） |

### 日数を省略した場合

日数を省略すると自動的に直近5日分になります。

```bash
python get_stock.py AAPL
```

### CSVとして保存したい場合

```bash
python get_stock.py 9418.T 10 --csv
```

実行したフォルダに `9418_T_20260728.csv` のようなファイルが作成されます。

### EMA（指数平滑移動平均線）の期間を選びたい場合

選べる期間は 5日・25日・75日・200日 の4種類です。デフォルトはこの4本すべてを表示します。
`--ema` にカンマ区切りで指定すると、表示する期間を絞り込めます。

```bash
python get_stock.py AAPL 20 --ema 25,75
```

## Claude Codeでの使い方

このフォルダをそのままClaude Codeのプロジェクトとして開いてください。
`CLAUDE.md` に使い方の指示を書いてあるので、チャットで

> 「9418の直近10日間の株価を見せて」

のように話しかけるだけで、Claude Codeが自動的にこのスクリプトを実行して結果を返してくれます。

## 注意点

- 株式分割・配当があった日はデータに反映されるまで時間差が出ることがあります
- 取引時間中に実行すると、当日分のデータが未確定のため表示されないことがあります（正常な動作です）
- 投資判断はご自身の責任で行ってください。このツールは情報取得を補助するものです
